# Story 1-1: Organização do Frontend (Rotas e Layout)

**Objetivo:**
Preparar a base estrutural do Frontend para exibir a interface de extração de Nota Fiscal de forma isolada e pronta para implementação dos demais requisitos.

**Tarefas a serem executadas:**
1. Criar e configurar as dependências de roteamento (ex: `react-router-dom`) se não existirem no projeto principal em `App.tsx`.
2. Criar uma nova pasta/componente voltada à nova aplicação (ex: `src/pages/NfExtraction/NfExtraction.tsx`).
3. Criar a rota (`/extracao-nf` ou `/financeiro/extracao-nf`) no menu de navegação lateral ou superior (`Navbar` ou `Sidebar`).
4. Desenvolver o wireframe estático vazio ("Aguardando Arquivo...") na nova tela, utilizando o sistema de design preferencial (ex: Tailwind CSS).

**Critérios de Aceite:**
- O usuário deve conseguir acessar a rota recém-criada através do menu de navegação.
- O CSS base deve estar funcional, mantendo consistência visual, cor e tema em uma tela limpa e amigável, preparada para os próximos passos da Figura 1 e Figura 2.
