# Story 4-0: Interface de Upload (Frontend Layout - FIGURA 1)

**Objetivo:**
Construir o container principal estático na visão de acordo com as especificações da Figura 1, preparando a página para que o usuário sinta uma excelente harmonia e estética ao utilizar o software.

**Tarefas a serem executadas:**
1. Em `NfExtraction.tsx`, criar um contêiner centralizado e usar flexbox/grid para organizar.
2. Adicionar os títulos, subtítulos ("Extração de Dados da NF") e textos explicativos.
3. Projetar e implementar o componente **Upload Area (File Input)**:
   - Adicionar uma zona "Drag N Drop" ou Input que visualmente mude de cor (hover effect).
   - Utilizar ícones (HeroIcons, Lucide React) de document/pdf para a área visual.
4. Mostrar o nome do arquivo após ele ser selecionado localmente no input e seu tamanho em (KB/MB).

**Critérios de Aceite:**
- A aparência gráfica precisa ser bonita, aderindo a margens padding equilibradas (ex: usando classes do Tailwind), com visual moderno.
- O componente precisa mostrar feedback visual que "temos" o arquivo pronto na máquina e seu nome ("arquivo.pdf").
